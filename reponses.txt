 merge

1. Initialisation du projet

mkdir TP2-ABERKANE-Adam
cd TP2-ABERKANE-Adam
git init
git status


2. Création du README et renommage de la branche

echo "# TP2 : Gestion des branches" > README.md
git add README.md
git commit -m "Ajout du fichier README.md avec le titre"
git branch -m develop


3. Création de la branche feature1 et modification

git switch -c feature1
echo "Ceci est une description du projet" >> README.md
git add README.md
git commit -m "Ajout d'une description du projet dans README.md"


4. Retour à develop, ajout d'une phrase et merge

git switch develop
sed -i '2i\Modification sur develop avant merge de f1.' README.md
git add README.md
git commit -m "Ajout d’une phrase avant le merge de feature1"
git merge feature1


5. Création de la branche feature2 et modification

git switch develop
git switch -c feature2
sed -i '1s/.*/# TP2 - ABERKANE Adam - Gestion des branches/' README.md
git add README.md
git commit -m "Modification du titre dans README.md pour feature2"


6. Création de feature3, modification et merge

git switch develop
git switch -c feature3
sed -i '1s/.*/TP2 - Gestion des branches et fusions/' README.md
git add README.md
git commit -m "Modification du titre dans README.md pour feature3"

git switch develop
git merge feature2
git merge feature3

Rebase
7. Création de feature4, rebase et nettoyage

git switch develop
git switch -c feature4
echo "Cette phrase concerne la partie rebase du TP2." >> README.md
git add README.md
git commit -m "Ajout dans README.md - partie rebase"

sed -i '$s/$/ (feature4)/' README.md
git add README.md
git commit -m "Ajout dans README.md - mention feature4"

echo "Fin des modifications de la feature f4" >> README.md
git add README.md
git commit -m "Ajout dans README.md - dernière ligne feature4"

git log --oneline
git rebase -i HEAD~2


8. Finalisation et mise à jour de develop

git switch develop
sed -i '1s/.*/ TP2 - Branches, merge et rebase - ABERKANE Adam/' README.md
git add README.md
git commit -m "Mise à jour du titre README.md pour develop"

git push -u origin develop
git rebase feature4
git add README.md
git rebase --continue
git push -f origin develop


9. Ajout du fichier réponses

git add reponses.txt
git commit -m "Ajout du fichier de réponses du TP"
git push
